# Кино-типографика

Стиль снят покадрово с 5 референсов пользователя (говорящая голова на улице/в студии, 1080x1920).
Движок общий с «Apple стекло»: `.claude/skills/apple-glass/engine/` (те же `render.js`, `compose.py`, звуки).

## Грамматика стиля

* Человек в центре, текст стоит **на груди** (центр блока ≈ y 1060), а не под подбородком.
* Каждая фраза — стопка 2–4 строк: мелкое разреженное слово → 1–2 ЖИРНЫХ слова → (курсив-акцент) → мелкое разреженное.
* Слова появляются **в момент произнесения**: из крупного расфокуса в резкость (scale 1.18 → 1, blur 14 → 0, 0.28 с).
  Блок уходит расфокусом (0.22 с). Без звука — звук только у печати и карточек.
* Между смысловыми блоками — **карточка-вспышка** на 0.5–0.8 с: чёрная `#121214`, кремовая `#f2eee7`,
  пыльно-розовая `#c79ea4` (текст бордовый `#5b1d2a`). На карточке: заголовок + список разреженных слов по одному.
* Когда человек стоит сбоку — **караоке-абзац** рядом с ним, выровненный к нему (влево/вправо): вся фраза серая, сказанное — белое.
* Акценты: `>что реально<`, `[ подпишись ]`, `вдолгую|` (курсор), курсив с «эхом» (два полупрозрачных следа слева).
* Внизу всегда фирменная подпись: имя моноширинным + крошечная строка капсом (`uvaisll / УВАЙСАЛ | REELS | ПРОДВИЖЕНИЕ`).
* Первый кадр — **силуэт**: человек залит чёрным 0.3–0.4 с, затем «проявляется».
* Крупное слово-заголовок можно поставить **за спину** — голова и плечи перекрывают буквы.
* Цвет: `GRADE=cinema`. Наезды плавные (`zoom` с `ramp` 0.5 с, ×1.08–1.12) на смене мысли.

## Размеры (кадр 1080x1920)

| Размер | Стиль | Пример |
|---|---|---|
| `sp` | 40 px / 400, разрядка 0.42em, строчные (на карточке 48 px) | «д а в н о», «з у б а х», «з а в и с и т» |
| `hb` | 118 px / 800, −0.05em | «мечтаете», «о ровных», «>что реально<» |
| `it` | 118 px / 800 курсив + эхо | «брекетов», «красивый» |
| `sub` | 34 px / 500 | «должен делать content maker» (часто с печатью) |
| `tag` | 28 px / 500, разрядка 0.22em | «[ подпишись ]» |
| `m` | 72 px / 500 | заголовок карточки «Будь это» |
| `para` | 52 px / 600 | караоке-абзац |

## Как делать ролик

Всё — из папки движка `E=.claude/skills/apple-glass/engine`, Python — `/root/venv-video/bin/python`.

1. Речь с таймингами слов: `subs-lab/asr.py` (или `video-tools/transcribe.py`).
2. Маска человека (нужна для «за спиной», силуэта, замены фона): `python $E/matte.py source.mp4 matte/` (~5 кадров/с).
3. `cues.json` по образцу `example_cues.json` рядом с этим файлом.
4. `node $E/render.js cues.json ov/`
5. `GRADE=cinema MATTE=matte python $E/compose.py source.mp4 ov/ out.mp4` (+ `FROM/TO` для куска, `SPEED`, `SFX_GAIN`).
6. Проверка: лист кадров по ключевым моментам + громкость. Правки — точечные.

## Элементы cues.json

```jsonc
{"type":"silhouette","t":0,"end":0.4,"color":"#000000"}                    // человек залит цветом
{"type":"mark","t":0,"end":60,"name":"uvaisll","sub":"увайсал | reels | продвижение"}   // подпись внизу
{"type":"words","fx":"cinema","t":0.45,"end":2.6,"pos":[540,1060],"lines":[  // стопка; pos можно не писать
   {"size":"sp","words":[["давно",0.45]]},
   {"size":"hb","words":[["мечтаете",0.70]]},
   {"size":"it","words":[["брекетов",1.05]]},
   {"size":"sub","type":true,"step":0.04,"words":[["должен делать content maker",1.4]]}]}  // печать с курсором
{"type":"title","t":2.75,"end":4.75,"text":"КИНО","size":300,"y":640,"behind":true,"label":"это"}  // ЗА спиной
{"type":"para","t":4.85,"end":6.45,"align":"left","pos":[90,1240],"lines":[[["Продажа",4.95],["—",5.15],["это",5.25]],[["совокупность",5.45]]]}
{"type":"flash","t":6.45,"end":7.15,"bg":"#121214","lines":[{"size":"m","text":"Будь это","t":6.5},{"size":"sp","text":"просмотры","t":6.7}]}
{"type":"flash","t":7.7,"end":8.3,"bg":"#c79ea4","ink":"#5b1d2a","lines":[{"size":"hb","text":"нанять","t":7.74}]}
{"type":"bg","t":10,"end":13,"src":"fire.mp4","dim":0.1}                   // замена фона за человеком (картинка или видео)
{"type":"zoom","t":2.6,"end":4.9,"scale":1.1,"ramp":0.5}                    // плавный наезд
```

`behind:true` работает у любого элемента (нужен `MATTE`). Также доступны все элементы «Apple стекло»:
`rain` (купюры), `leak` (засветка), `blur`, `card`, `focus`, `cta`.

## Звуки (из пака пользователя — Botanica v5, через `sfx_map.json` → `sfx_local`)

Звуки референсов разобраны по спектрограммам. Пак пользователя найден в видео 4 точно (сопоставление
спектров, z > 11): `Pop, Button, Scale, Transform, Ui_8/_9` на тегах и `Type (one)` на печати. Для
остальных референсов взят ближайший по спектру звук пака.

| Событие | Роль | Звук пака | Громкость |
|---|---|---|---|
| строка / пункт списка на карточке | `cardclick` | Pop, Button, Scale, Transform, Ui | 0.30 |
| тег `[ … ]` | `tagpop` | Pop, Button, Scale, Transform, Ui_8 | 0.28 |
| печать с курсором (каждая буква) | `key1..4` | Type (one) 1–4 | 0.10 |
| заголовок печатается | `key1..4` | Type (one) 1–4 | 0.24 |
| плавный наезд (`zoom` с `ramp`) | `whoosh` | Laser | 0.24 |
| особый объект (3D, логотип, слово за спиной) | `chime` — `"sound":"chime"` у элемента | Select, Gratonal, Gleam_5 | 0.24 |

Правило: **слова-стопка на груди и караоке-абзац — без звука**, только голос. Музыки нет.
Любой элемент может получить звук: `"sound":"роль"`, `"soundAt":0.1`, `"soundGain":0.3`.
Без пака работают синтезированные заменители из `engine/sfx/` (те же роли).

## Проверено

Демо на собственном ролике пользователя (9.5 с): силуэт, стопка из расфокуса, «КИНО» за спиной
(голова перекрывает «К»), караоке-абзац, три карточки, печать с курсором, кинотонировка — всё отрабатывает.
Маска MediaPipe мягкая: на быстрых движениях рук край размывается.

## Нельзя

* Коммитить видео пользователя/референсы и файлы купленных звуковых паков.
* Менять всё сразу при правках — только то, что сказано.
