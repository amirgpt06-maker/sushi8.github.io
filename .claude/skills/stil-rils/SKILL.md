# Стиль рилс

Снят с 25 рилсов из папки пользователя (26-й файл — дубль). Общая длина 14 минут. Каждый ролик просмотрен
по раскадровке 2 кадра/с, ключевые анимации — покадрово (12–15 кадров/с), речь расшифрована по словам.
**Падающие деньги в стиль не входят** (просьба пользователя).

Что измерено, а что оценка:
* тайминги, размеры, цвета, ритм — сняты с кадров;
* шрифты — определены по виду, названы ближайшие аналоги (точное имя файла шрифта по видео узнать нельзя);
* звук — разобран по спектрограммам и замерам (раздел 12), на слух не оценивался.

## 1. Суть в шести строках

1. Человек в кадре, текст **на груди**, блок узкий: 35–55 % ширины кадра. Никаких полос субтитров снизу.
2. Один плотный гротеск в трёх ролях: **мелкое тонкое → КРУПНОЕ ЖИРНОЕ → мелкое**. Акцент — *курсив* или разрядка букв.
3. Текст идёт **по словам речи**: следующее слово сначала серое-полупрозрачное, потом белеет.
4. Всё появляется **из размытия** и уходит в размытие. Жёстких выскакиваний нет.
5. Каждые 5–10 секунд — смена картинки: карточка-вспышка одного цвета, стеклянная карточка с фото, вставка интерфейса, 3D-предмет.
6. Картинка киношная: тёплая или зелёно-бирюзовая тонировка, тёмная виньетка снизу, малая глубина резкости.

Правила набора:
* Цвет текста — белый `#FFFFFF`. «Ещё не сказанное» — тот же белый, непрозрачность 30–45 %.
* Тень едва заметная, мягкая (размытие 20–30 px, непрозрачность 25–35 %). Обводки нет. Плашек под текстом нет.
* Почти всё строчными. Капсом — только одно ударное слово или узкий шрифт.
* Вторая строка стопки часто сдвинута вправо на 5–10 % ширины («лесенка»).
* Английское слово вместо русского как акцент: `everyone`, `biohacking`, `content maker`, `Saudi Arabia`.

## 4. Анимации текста

Все цифры сняты покадрово.

**Появление**
* **Из размытия** — основной приём. Строка проявляется за 0.15–0.25 с: размытие 12–20 px → 0, масштаб 106 % → 100 %.
* **Стопка собирается сверху вниз**, шаг между строками 0.12–0.16 с. Мелкая разреженная строка — последней, выезжает снизу.
* **Серое → белое.** Блок целиком проявляется серым за 0.15 с, слова белеют по одному в момент произнесения.
* **Печать по буквам с курсором `|`**, 20–25 знаков в секунду. Для вопросов, цитат, моноширинных строк.
* **Мерцающая печать** — буквы появляются не по порядку (v17, v18).
* **Разрядка схлопывается**: `П Р О Д` печатается вразрядку и сжимается в нормальное слово (v22).
* **Влёт сбоку со смазом** 0.2 с — для второго крупного слова (v02).
* **Рост из точки** 0 → 100 % за 0.2 с — для короткого ударного слова (`da`, v07).

**Удержание**: 0.6–1.5 с. Одно слово — 0.3–0.5 с.

**Уход**
* В размытие и затемнение за 0.2–0.25 с, строки гаснут снизу вверх.
* Обратная печать: слово стирается по буквам, на его месте печатается следующее (v17, v26).
* 3D-поворот с подменой слова за 0.13 с (v02).
* Белый пересвет текста на 1 кадр и исчезновение (v13).
* Титул уезжает за край кадра (v24).

**Пульс**: крупная цифра или слово плавно уменьшается 105 % → 100 % за время удержания.

## 5. Вставки

**Карточка-вспышка** (v10, v16, v17, v20, v22, v23, v26) — весь кадр заливается одним цветом, по центру одно-два слова.
* Длительность 0.4–1.5 с. В счёте — по 2 кадра (0.08 с), фон мигает светлый/тёмный.
* Цвета: чёрный `#111111`, светло-серый `#E6E6E6`, кремовый `#F3F1E8`, серый `#666666`, фисташковый `#A9BF9C`,
  пыльно-розовый `#C79EA6`, сиреневый `#A09CC4`, градиент бренда (чёрный → оранжево-коричневый).
* На цветной карточке слово **того же тона, но темнее** (розовый фон — бордовое слово).
* Слово либо разреженное тонкое, либо жирное + мелкая строка.
* Шапка и подвал карточки: мелко `inst / ник` сверху, `tg / имя` снизу. Водяной знак остаётся.
* Украшения: мягкие светящиеся блёстки, меловые каракули-нули вокруг слова.

**Стеклянная карточка с фото** (v18) — скруглённый прямоугольник «матовое стекло» с наклоном −12°.
* Сначала пустое стекло с тёплым жёлтым свечением 0.3 с, затем сквозь него проявляется фото за 0.4 с.
* Фон в этот момент размывается и темнеет за 0.3 с.
* Следующие карточки ложатся поверх веером, шаг около 1 с. Под колодой — имя жирным и мелкая должность.

**Стеклянная плашка-вопрос** (v23) — матовая скруглённая плашка с аватаркой-кругом на верхней кромке.
Вырастает из точки за 0.3 с, вопрос печатается с курсором, плашка растёт вместе со строками. Ответ — в плашке поменьше.

**Вставки интерфейса** — главное отличие стиля от обычных субтитров:
* кнопка «Подписаться» → курсор → «Вы подписаны» (v06, v13, v18, v24);
* рамка сторис поверх кадра: полоса прогресса, аватар, ник, поле «Отправить сообщение…» (v22, v19);
* шторка снизу «Отметки Нравится и просмотры» со счётчиками (v21);
* интерфейс рилса поверх нарезки: сердце, комментарий, ник, Follow (v09);
* карточка профиля: ник, аватар с градиентным кольцом, ссылка (v08, v12);
* папка macOS, иконка Face ID, геометка, опрос «ДА / НЕТ» (v11, v15, v21).

**Предмет на тёмном фоне** (v24, v16, v15) — 3D-модель или вырезанный предмет вращается по центру.
Вокруг тонкие круги-прицелы, рядом мелкая подпись. Фон — тёмный градиент или размытый кадр.

**Скриншот-доказательство** (v10) — скрин на весь кадр, медленный наезд, затемнение 40 %, поверх одна белая строка.

**Прочее**
* фото-карточки «до/после» выезжают снизу (v10);
* ч/б фигура другого человека со штриховкой за спиной героя (v04);
* тонкая линия-аудиоволна на груди вместо текста (v04);
* выноска: тонкая белая линия с точками на концах тянется к руке, рядом крупная тонкая цифра (v16);
* рамка-прицел следит за предметом в руке (v23);
* неон: светящиеся надписи и линии, рамка вокруг карточки (v08, v14);
* контур карты с адресами (v14);
* сплит-экран из 2–3 горизонтальных полос (v01, v09);
* цветное свечение на объекте: фары загораются оранжевым на 0.25 с (v05).

## 6. Переходы

| Переход | Как сделан | Длительность |
|---|---|---|
| Прямая склейка со сменой крупности | общий → крупный, основной приём у «говорящей головы» | 0 |
| Через размытие | кадр уходит в блюр, следующий выходит из блюра | 0.3–0.4 с |
| Вспышка-пересвет | 1–2 кадра кадр выбелен | 0.04–0.08 с |
| Цветная засветка | красная, оранжевая или фиолетовая заливка на 2–4 кадра | 0.1–0.15 с |
| Силуэт-маска | чёрный силуэт человека → белый → обычный кадр | 0.24 с |
| «Рентген» | 2 кадра негатива или белой фигуры поверх следующего плана | 0.08 с |
| Смаз (whip) | резкий горизонтальный смаз камеры | 0.15–0.2 с |
| Влёт в объект | наезд в решётку, фару, экран с затемнением | 0.4–0.6 с |
| Рука закрывает кадр | ладонь перекрывает объектив, за ней новый план | 0.2 с |
| Цвет → ч/б → цвет | акцент на фразе, не склейка | 0.5–1 с |
| Формой логотипа | логотип вырастает на весь кадр | 0.3 с |
| Глитч | пиксельные блоки на 2–3 кадра | 0.1 с |
| Полароид | кадр на миг становится ч/б отпечатком с белой рамкой | 0.1 с |
| 3D-переворот карточки | план въезжает наклонной плоскостью | 0.3 с |

Правило: спецпереход ставится на смену мысли. Внутри мысли — прямые склейки и смена крупности.

## 7. Картинка и цвет

* Тонировка киношная: тёплые тени или зелёно-бирюзовый оттенок, приглушённая насыщенность, мягкий контраст.
* Тёмная виньетка-градиент снизу на 25–35 % высоты кадра, чтобы низ не спорил с текстом.
* Малая глубина резкости: фон размыт, человек резкий.
* Под вставку фон размывается (20–30 px) и темнеет на 30–50 %.
* Цвет текста белый. Цветной акцент один на ролик: светло-зелёный, оранжевый, серебристый или цвет бренда.
* Локации меняются на каждой мысли либо один план с тремя крупностями.

## 8. Хук (первые 2 секунды)

Текст появляется не позже 0.15 с от начала. Варианты:
1. Крупная стопка-вопрос сразу на груди (v16, v09, v17).
2. Вопрос в стеклянной плашке с аватаркой, печатается (v23).
3. Огромное слово за головой (v10).
4. Титул «имя гротеском + фамилия рукописным» с фото-карточкой и меткой `[совет]` (v20).
5. Титул в стрелках `>Реально СТИЛЬНО?<` (v18).
6. Старт из сильного размытия всего кадра (v13) или с силуэта (v23).
7. Предмет в кадре + сразу вставка с 3D-моделью (v24).
8. Замена фона на первой же фразе: огонь, руины (v02, v22).

## 10. Водяной знак

Стоит весь ролик, в том числе на карточках. Два варианта:
* снизу по центру, моноширинный, 2 строки: ник вразрядку / `имя | reels | продвижение` (v16, v23);
* рукописная подпись-росчерк, мелко, слева у плеча или снизу по центру (v07, v12, v13, v20).
Непрозрачность 60–80 %. Высота: 82–88 % кадра.

## 11. Ритм

* Длина: медиана 29.5 с, от 10 до 62 с.
* Речь: медиана 2.6 слова в секунду (2.2–3.1). Пауз между фразами почти нет.
* Новый текст на экране каждые 0.3–1.5 с.
* Смена плана: 1.5–5 с в динамичных роликах; в роликах с одним планом динамику держит текст и вставки.
* Вставка (карточка, интерфейс, предмет) каждые 5–10 с.

## 12. Звук (разбор дорожек всех 25 рилсов)

Как разбирал: спектрограммы дорожек, поиск эффектов в полосе выше 6 кГц (там речи почти нет), отсев шипящих звуков речи,
кадры «до / в момент / после» каждого звука. На слух не проверял. Глухие низкие звуки (мягкие удары) этот способ
пропускает, поэтому счёт звуков — нижняя граница.

**Звуков мало.** В роликах с речью один слышимый эффект на 3–4 секунды (медиана по роликам 3.9 с; в самых насыщенных 1.6 с, в самых тихих реже 10 с). Не на каждое слово.

**На чём стоит звук** (по кадрам вокруг 164 найденных эффектов):

| Событие в кадре | Звук | Длина | Уровень* |
|---|---|---|---|
| появился новый крупный блок текста (стопка, титул) | короткий воздушный вжух | 0.3–0.45 с | −13 дБ |
| блок, который «въезжает» или собирается дольше | нарастающий вжух | 0.4–0.7 с | −16 дБ |
| вставка появилась (плашка, карточка с фото, предмет), пункт списка | поп | 0.08–0.2 с | −18 дБ |
| карточка-вспышка, смена слова на карточке | тихий щелчок-переключатель | 0.03–0.07 с | −24 дБ |
| печать текста в плашке | 1–2 тихих клавиши на фразу, не на каждую букву | 0.03 с | −24…−28 дБ |
| ключевое слово, большой титул, переход в новую часть | райзер перед ним | около 1 с | −10 дБ |
| интерфейсная вставка, 3D-предмет | короткий тональный бип | 0.05–0.1 с | −22 дБ |
| нажатие кнопки «Подписаться» | клик | 0.1–0.2 с | −12…−14 дБ |

*Уровень — пик эффекта в полосе 6–16 кГц относительно уровня речи в полосе 300–3000 Гц (75-й перцентиль). Так же меряет
`compose_sr.py` при сборке, поэтому громкость выставляется по той же линейке, что в референсах.

**На чём звука нет:**
* на словах, которые появляются по одному, и на абзаце-караоке;
* на обычных склейках: на склейку попадает только 14 % звуков (вжух на каждой смене плана — ошибка первой пробной версии);
* подряд очередями: пауза между соседними звуками — медиана 2.2 с, и только 19 % пауз короче секунды.

**Виды звуков по частоте:** поп 31 %, вжух 30 %, нарастающий вжух 16 %, щелчок 12 %, райзер 6 %, бип 3 %.

**Музыка:** в трёх роликах без речи и ещё в трёх под голосом есть музыкальная подложка. У нас действует правило пользователя:
без музыки, только эффекты и тихий нашид.

**Какие файлы пака использовать.** Пак лежит в той же папке Drive («isla pac», 166 звуков). Точно опознать файл по записи
удаётся редко (уверенных совпадений 17 из 164), но чаще других совпадали: `Whooshes_ODC-0002-506.wav`, `Saas Sfx.mp3`,
`clickbutton.mp3`, `iphone-keyboard-typing-sound-effect`, `переключатель.mp3`, `эпл печатание.mp3`, `Резкие вуши.mp3`.

## 13. Что из стиля берём с поправкой на правила пользователя

* Деньги не используем.
* Палитра блога: белый и синий. Акцентный цвет — `#4C8DFF` вместо зелёного и оранжевого.
* Без музыки. Без женщин и без чужих лиц в стоке.
* Вставки интерфейса — только свои (ник `saidulaev.ai`, свой аватар), чужие аккаунты не копируем.

## 14. Рецепт ролика в «стиле рилс»

| Время | Что на экране |
|---|---|
| 0.0–0.15 с | кадр выходит из размытия или с силуэта |
| 0.15–2.5 с | хук: стопка-вопрос на груди или вопрос в стеклянной плашке |
| 2.5–8 с | абзац-караоке или пары «жирный + курсив», смена крупности на склейках |
| 8–10 с | первая вставка: 2–4 карточки-вспышки подряд по 0.5–1 с |
| 10–18 с | стопки по словам, одно слово за спиной или цифра-счётчик |
| 18–22 с | вторая вставка: стеклянная карточка, предмет или свой интерфейс |
| 22–27 с | вывод крупной стопкой, список столбиком |
| последние 2–3 с | призыв: кнопка «Подписаться» с курсором или стрелка-шеврон |

Проверка перед сдачей:
- [ ] блок текста не шире 55 % кадра и стоит на груди;
- [ ] в стопке три разных кегля, крупное слово одно;
- [ ] ни одно слово не выскакивает резко: всё из размытия или печатью;
- [ ] следующее слово сначала серое;
- [ ] есть минимум две вставки и один спецпереход на смену мысли;
- [ ] водяной знак на месте весь ролик;
- [ ] снизу тёмный градиент, фон под вставками размыт.
