# Разбор аккаунта

## Инструменты
`ffmpeg`, `yt-dlp`, `faster-whisper`, `instaloader` (+ `gallery-dl` про запас) — в `/root/venv-video`, ссылки в `/usr/local/bin`.
Если нет: `/root/venv-video/bin/pip install yt-dlp faster-whisper instaloader gallery-dl`. Разбор одного рилса —
скрипт скилла `razbor-rilsa` (используется отсюда).

## Вход (обязательно)
Instagram не отдаёт ленту профиля без входа. Берём cookies **запасного** аккаунта пользователя:
* на компьютере пользователя с Chrome — `--browser chrome`;
* в облачной сессии Chrome нет — нужен файл `cookies.txt` (Chrome → расширение «Get cookies.txt LOCALLY» → на instagram.com
  «Export»), положить в `reels/cookies.txt` и передать `--cookies reels/cookies.txt`. Файл не коммитить (`*cookies*.txt` в
  .gitignore), не показывать, после работы можно удалить. Если cookies протухли — скрипт скажет, попросить свежие.

## Шаг 1 — данные
```
/root/venv-video/bin/python .claude/skills/razbor-akkaunta/scripts/akkaunt.py <ник> --cookies reels/cookies.txt
```
* берёт не больше 50 последних рилсов, между запросами паузы 2–9 с (instaloader ещё и сам притормаживает) — чтобы
  Instagram не заблокировал запасной аккаунт; при «Please wait a few minutes» — остановиться и сказать пользователю;
* `reports/<ник>/reels.json` — все рилсы по убыванию просмотров: дата, просмотры, лайки, комментарии, длительность, подпись,
  `x_avg` (во сколько раз больше среднего), `viral` (≥ 3× среднего по аккаунту);
* топ-10 по просмотрам скачиваются и готовятся скриптом `razbor-rilsa`: `reports/<ник>/<shortcode>/` — кадры (первые 3 с
  каждые 0.5 с, дальше 1/с), `hook.jpg`, `sheet_*.jpg`, `transcript.txt/json` (ru, таймкоды), `data.json`
  (склейки, темп, громкость); **видео удаляется сразу после обработки**.
Сказать заранее, сколько ждать: список ≈ 2–5 мин, каждый рилс ≈ 1–2 мин (расшифровка на CPU).

## Шаг 2 — разбор топ-10
Для каждого рилса прочитать `hook.jpg`, `sheet_*.jpg`, `transcript.txt`, `data.json` и записать `reports/<ник>/<shortcode>/razbor.md`
по схеме `razbor-rilsa`: хук (0–3 с: экран + дословно речь), структура по секундам (боль / польза / призыв), монтаж (темп
склеек, субтитры, эффекты, звук), призыв, почему залетел — сначала искать **фоновое удержание** (что в кадре всё время
«вот-вот случится»). Ничего не выдумывать.

## Шаг 3 — итоговый отчёт `reports/<ник>.md`
1. Шапка: ник, подписчики, сколько рилсов взято, средние просмотры, сколько залетевших.
2. **Таблица всех рилсов**: дата | тема (по подписи/речи, 3–6 слов) | просмотры | лайки | комм. | ×среднего | 🔥 если залетел.
3. **Что общего у залетевших**: темы, хуки (дословно, с приёмом), длина, форматы (говорящая голова / скетч / экран / B-roll),
   темп монтажа, субтитры, звук, призывы — с цифрами (средняя длина, склеек в первые 3 с и т.п.).
4. **5 идей для блога пользователя про ИИ** (saidulaev.ai, нейросети простыми словами): формат-источник, хук дословно
   (первые 3 с: что на экране и что сказать), структура по секундам, призыв. Правила пользователя: без лиц посторонних и
   без женщин в кадре, без музыки без просьбы, монтаж — skill `montazh`.
Отчёт отправить пользователю файлом (SendUserFile) и коротко пересказать в чате. `reports/` в git не попадает.
