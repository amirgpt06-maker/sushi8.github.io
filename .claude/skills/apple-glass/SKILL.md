# Apple стекло

Стиль снят покадрово с референса пользователя (говорящая голова, 1080x1920, 30 к/с, 36 с) и
воспроизведён своим кодом и своими синтезированными звуками. Движок — в `engine/` рядом с этим файлом.

## Когда что использовать (грамматика стиля)

Ролик — это чередование трёх «режимов», переходы между ними и есть монтаж:

| Режим | Что на экране | Когда |
|---|---|---|
| **Живой** | резкое видео, субтитры-стопка под подбородком, двигаются вместе с головой | обычная речь |
| **Стекло** | фон размыт (σ≈26) и затемнён ~50 %, поверх — карточка или крупный заголовок | перечисление, сравнение цен, названия, цифры |
| **Вспышка** | чистый белый или чёрный экран, мелкий текст по центру печатается по буквам | 2–4 слова-«удара» подряд (белый → чёрный → белый), последнее слово — оранжевое |

Переходы:
* Живой → Стекло: фокус-рамка (4 стрелки сходятся к лицу и раскрываются) + фон уходит в размытие за 0.28 с.
* Стекло → Живой: карточка растворяется «стеклом» (рябь-преломление + расфокус, 0.5 с), фон резкий, снова фокус-рамка (раскрылась — схлопнулась).
* Вспышка → Живой: световая засветка (оранжево-розовая, 0.45 с) + резкий наезд ×1.12.
* Живой → Стекло (динамично): дождь из купюр, последняя огромная купюра закрывает кадр — склейка прячется за ней.
* Заголовок → заголовок: старый блок уходит вверх с расфокусом (0.18 с), новый печатается; или буквы перемешиваются (TAOBAO → POIZON, 0.42 с).
* Подпись → подпись: свайп влево со смазом (+ двойной клик мыши) или быстрый расфокус.

## Типографика (замерено, кадр 1080x1920)

Шрифт: Inter (замена SF Pro), белый, лёгкая тень `0 2px 18px rgba(0,0,0,.28)`, плотная разрядка.

| Класс | Размер / жирность | Пример |
|---|---|---|
| `s` — мелкое слово | 40 px / 400 | «этот», «набор», «и даже», «на этом» |
| `m` — фраза | 72 px / 500, −0.035em | «все думают», «Китай сложно» |
| `l` — ключевое слово | 98 px / 600, −0.045em | «Детский», «разница» |
| `caps` — акцент | 82 px / 800, ВЕРХНИЙ РЕГИСТР | «ЗАРАБАТЫВАЮ», «ЗАКУПАЮТ СВОЙ», «ОТПРАВЬ» |
| `xl` — заголовок на стекле | 206 px / 700 (названия 150 px) | «1688», «TAOBAO», «POIZON» |
| `label` | 48 px / 400 | «маркетплейс» над/под заголовком |
| подписи карточки | 56 px / 400 | «Wildberries» сверху, «от 1200р» снизу |
| вспышка | 62 px / 400, чёрный на белом / белый на чёрном | «пока не», «обучился», «этому» |

Стопка: мелкое слово выровнено по левому краю ключевого (сверху) или по правому (снизу), строки почти
касаются (line-height ≈ 0.9). Блок стоит по центру под подбородком: `y = лицо.cy + 0.80·лицо.h`
(≈ 0.66 H), x следует за головой. Отдельное слово внутри строки можно сделать жирным (`"b"`, «**wb**-ки»)
или акцентным оранжевым (`"a"`, #F28C28).

Раскладка «стекла»: подпись сверху y≈0.21 H, карточка 696x696 по центру (радиус 52), подпись снизу
y≈0.72 H. Заголовок сначала по центру (y 960), потом уезжает вверх к y≈470 с 3D-взмахом (rotateX до 26°,
rotateZ −4°), пояснение появляется ниже (y≈1180).

## Анимации

* **Появление слова** — мягкая градиентная шторка слева направо + расфокус 7 px → 0, длительность
  `0.03·букв + 0.08` (0.14–0.42 с), блок при первом слове всплывает на 16 px. Слова появляются
  **ровно в момент произнесения** (тайминги — из распознавания речи).
* **Печать по буквам** (вспышки, заголовки) — шаг 45–70 мс, каждая буква: прозрачность, расфокус,
  серый → белый; во вспышке разрядка сжимается 0.32em → 0.
* **Карточка** — влёт пружиной 0.62 с: из scale .84, rotateZ 9°, rotateY −24°, rotateX 10°, сдвиг (70, −90).
* **Перелистывание со стеклом** — за 0.9 с до смены появляется стеклянная линза (Ø ≈ 145 px, тонкий светлый обод,
  преломление/увеличение, блик) справа от верхней подписи; карточка «отступает» до 0.83; линза проезжает
  влево как палец, подписи уезжают влево со смазом, новые въезжают справа; карточка возвращается, линза
  дрейфует обратно и гаснет.
* **Стеклянное растворение** — feTurbulence + feDisplacementMap (до 90) + расфокус до 16 px + исчезновение, 0.5 с.
* **Фокус-рамка** — 4 стрелки ↘↙↗↖ от центра лица раскрываются к углам глаз/подбородка (0.32 с), в конце схлопываются.
* **Призыв** — `caps` слово + мелкое `"+"` + шеврон вниз, качается ±9 px с периодом 0.9 с.

## Звуки (свои, синтез: `engine/sfx.py`, параметры — со спектрограммы референса)

| Звук | Где | Характер |
|---|---|---|
| `key1..4` | печать во вспышках, заголовках, пояснениях на стекле | механическая клавиатура, щелчок 3–5 мс + «тело» 170–220 Гц, пачка с шагом 35–60 мс |
| `tink` | влёт карточки, появление линзы | стекло: 3.25 / 6.5 / 9.8 / 13 кГц, 25–60 мс |
| `click2` | перелистывание, свайп подписи | мышь: нажал/отпустил через 70 мс |
| `pop` | первое слово ролика, призыв | мягкий пузырь < 2 кГц |
| `air` | чёрная вспышка | ровный шум 0.6 с |
| `riser` | световая засветка | низкий гул, нарастает до 5 кГц, 0.75 с |
| `cash` | дождь из купюр | «ка-чинг», звон 2.2/5.6/6.1/10.2 кГц |
| `swoosh` | огромная купюра-шторка, взмах заголовка | короткий свайп 0.3 с |
| `shimmer` | стеклянное растворение | шорох + высокие искры |
| `focus` | фокус-рамка | очень тихий тон 1.25 + 2.7 кГц |

Правило из референса: **живые субтитры под лицом — без звука** (только голос); звук печати — у текста
на вспышках и на размытом фоне. Музыки нет. Итог: −14 LUFS, пик −1.5 dBTP.

## Как делать ролик

1. Исходник: вертикальное видео. Если звук грязный — `video-tools/clean_audio.sh`.
2. Распознать речь с таймингами слов: `subs-lab/asr.py` (Whisper turbo офлайн) или `video-tools/transcribe.py`.
   Найти склейки (`scenedetect` в `/root/venv-video`).
3. Якорь-лицо: `/root/venv-video/bin/python engine/anchor.py source.mp4 anchor.json`.
4. Написать `cues.json` (формат ниже; пример — `engine/example_cues.json`). Разбить речь на стопки по 1–3 слова,
   выбрать моменты для «стекла», «вспышек», засветки и дождя по смыслу (цифры, цены, названия, кульминация).
5. Рендер оверлея: `node engine/render.js cues.json ov/` (≈ 14 кадров/с; можно кусками `from to`).
6. Сборка: `/root/venv-video/bin/python engine/compose.py source.mp4 ov/ out.mp4`
   (`FROM=… TO=…` — проверить кусок; `SPEED=1.03` — лёгкое ускорение; `SFX_GAIN=0.8` — тише эффекты;
   `AUDIO_ONLY=1` — пересобрать только звук). ≈ 2.3 кадра/с (36 с ролика ≈ 8 мин) — запускать в фоне.
   Метаданные (GPS) вырезаются.
7. Проверить: контактный лист кадров на ключевых моментах + громкость (`ffmpeg -af ebur128`).
   Правки — точечные, по одному параметру, не перекраивать весь ролик.

Звуки уже лежат в `engine/sfx/`; пересоздать: `/root/venv-video/bin/python engine/sfx.py`.

## Формат cues.json

```jsonc
{
 "fps": 30, "duration": 36.1, "anchor": "anchor.json", "accent": "#F28C28",
 "items": [
  // живая стопка: строки s/m/l/caps, у каждого слова — время произнесения; "b" жирное, "a" акцент
  {"type":"words","t":0.10,"end":1.20,"sfx":"pop","exit":"fade|swipe","lines":[
     {"size":"s","align":"left","words":[["этот",0.10]]},
     {"size":"l","words":[["Детский",0.16]]},
     {"size":"s","align":"right","words":[["набор",0.40]]}]},
  {"type":"focus","t":0.80,"end":1.50},                          // фокус-рамка на лице
  {"type":"blur","t":1.00,"end":7.70,"dim":0.5,"in":0.28,"out":0.32},  // размытый фон
  {"type":"card","t":1.35,"end":7.65,"img":"product.jpg","lens":true,"exit":"glass|cut","pages":[
     {"t":1.35,"top":"Wildberries","bottom":"от 1200р"},
     {"t":4.30,"top":"Китай","bottom":"от 360р"}]},             // вторая страница = перелистывание со стеклом
  {"type":"flash","t":13.33,"end":13.80,"bg":"#ffffff","text":"пока не"},
  {"type":"flash","t":13.80,"end":14.37,"bg":"#000000","text":"обучился","air":true},
  {"type":"flash","t":14.37,"end":15.00,"bg":"#ffffff","text":"этому","accent":"#E58A1F","accentAt":14.80},
  {"type":"leak","t":14.97,"dur":0.45},                           // световая засветка
  {"type":"zoom","t":15.00,"end":17.27,"scale":1.12,"ramp":0},    // ramp>0 — плавный наезд
  {"type":"rain","t":17.00,"end":19.62,"n":16,"cover":true},      // купюры (или "emoji":"🍎")
  {"type":"title","t":19.75,"end":24.58,"text":"1688","label":"маркетплейс","labelT":20.95,"up":21.45,
     "sub":[{"size":"m","words":[["где",22.38],["все",22.55],["wb-ки",22.72,"b"]]},
            {"size":"caps","words":[["закупают",23.00],["свой",23.32]]},
            {"size":"s","words":[["товар",23.62]]}]},
  {"type":"title","t":24.62,"end":28.40,"text":"TAOBAO","size":150,"label":"где качественная розница","under":"маркетплейс"},
  {"type":"title","t":28.40,"end":29.50,"text":"POIZON","size":150,"from":"TAOBAO","label":"маркетплейс"},  // перемешивание букв
  {"type":"cta","t":31.80,"end":36.10,"text":"ОТПРАВЬ","sub":"\"+\""}
 ]
}
```

`img` — путь относительно cues.json (или `"emoji":"🎬"` вместо фото). `pos:[x,y]` у `words`/`cta` —
закрепить блок вручную вместо привязки к лицу. `sfx:false` у `title`/`cta` — без звука.

## Проверено

* Позиции и размеры сверены наложением на референс: стопки, карточка, подписи, заголовки совпадают с
  оригиналом в пределах ~10–20 px.
* Демо со всеми элементами — `engine/example_cues.json` (на любом вертикальном фоне).

## Нельзя

* Брать звуки/картинки из чужих роликов — только свои (синтез) или CC0.
* Коммитить личные видео пользователя и референсы; в отдаваемых файлах — без метаданных.
* Менять всё сразу при правках: пользователь просит «аккуратно, миллиметрично» — правим ровно то, что сказано.
