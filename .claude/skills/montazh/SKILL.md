# Наш стиль монтажа

Один стиль. Собран из всего, что пользователь присылал: референс со стеклом, 4 «эпл» ролика (`style-lab/STYLE.md`),
10 роликов из папки (кино-типографика, интерфейс, документальный, авто-блог, 3D-текст), звуковой пак, и из всех его правок
в чате. Отдельных названий больше нет. Что убрать или поменять — пользователь скажет; правки вносим в этот файл.

Движок: `engine/` рядом с этим файлом (`render.js` + `engine.html` — оверлей, `compose.py` — сборка, `anchor.py` — лицо,
`matte.py` — маска человека, `sfx*.py` — звуки). Python — `/root/venv-video/bin/python`.

## Главные правила (из правок пользователя)

1. **Премиально, не «мультик».** Много воздуха, мало цветов: белый текст, акцент оранжевый `#F28C28`. Ничего кислотного.
2. **Текст строго по речи**: каждое слово появляется в момент, когда его сказали (тайминги каждого слова — `video-tools/words.py`).
   Подпись держится, пока её можно прочитать, — до следующей мысли, не мигает.
3. **Читаемость прежде всего.** На светлом видео — `"textShadow": true`; под субтитрами внизу — мягкий тёмный градиент, без
   плашек-карточек под текстом. Текст белый или жёлто-оранжевый.
4. **Без виньетки и затемнения углов** (по умолчанию выключено; `VIGNETTE=1` — только если попросят).
5. **Без музыки.** Голос главный. Звуки — из пака пользователя, по схеме его референсов (см. «Звук»), не пачками.
   Печать — **не на каждую букву** (звучит как пустая дробь по клавиатуре): щелчок на начало слова и дальше раз в 3 буквы
   внутри длинного слова (`"typeEvery": 3` в cues; 2 — чаще, 99 — только на слово).
6. **Правки — точечные, «миллиметрично».** Меняем ровно то, что сказано; размеры/позиции, которые пользователь одобрил, не трогаем.
7. **Лица посторонних** (дети, ученики) — размыть только овал лица (брови–подбородок, часть бороды видна), мягкий край:
   `subs-lab/facetrack.py` + `blur_faces` из `subs-lab/compose.py`.
8. **Иконки** — цветные эмодзи (Noto Color Emoji), не линейные; живые существа — тёмным силуэтом (`|shadow`).
9. Лёгкое ускорение всего ролика `SPEED=1.03`, если речь медленная.
10. Перед работой сказать, **сколько ждать**; по ходу — коротко, что делаю. Готовый ролик — файлом в чат, без метаданных (GPS).
11. **HDR с iPhone (HLG, BT.2020, 10 бит) — всегда переводить в SDR тонмаппингом**, иначе картинка пересвечена и блёклая
    (так было в первой рекламе мотоцикла — пользователь: «яркость очень большая, я не просил»). Проверка: `ffprobe … color_transfer`;
    `arib-std-b67` или `smpte2084` → `zscale=t=linear:npl=150,format=gbrpf32le,zscale=p=bt709,tonemap=hable:desat=0,zscale=t=bt709:m=bt709:r=tv,format=yuv420p`.
    После тонмаппинга — только наша `GRADE=film` (сохраняет яркость), никаких самодельных осветлений.
12. **Чистый звук голоса**: `highpass=f=90:poles=2,arnndn=m=~/video-models/rnnoise/std.rnnn:mix=0.9,afftdn=nr=10:nf=-45,
    equalizer=f=250:t=q:w=1:g=-1.5,equalizer=f=4500:t=q:w=1.2:g=1.5,acompressor=threshold=-22dB:ratio=2.5:attack=8:release=120:makeup=2`
    (ветер и шум в паузах −5…−15 дБ, голос не «роботизируется»). Замерить шум в паузах до/после.
14. **Стабилизация** — `python video-tools/stabilize.py in.mov stab.mp4 [сглаживание_с]` (по фону, человек не учитывается;
    каждый кадр сверяется с опорным — без накопления ошибки; сбои слежения отбрасываются). `0` — как на штативе
    (масштаб ~1.1–1.16), `3` — мягкая ручная камера (~1.08). Встроенный vidstab для говорящей головы не годится:
    цепляется за движения человека. Проверка: наложить 4 кадра — стена и картина должны совпасть.
15. **Речь не на русском** (чеченский и др.): подписи только на русские слова, которые точно распознаны
    (`video-tools/words.py` + буквенные тайминги), остальное — без текста; смысл не выдумывать.
13. **Без зерна и прочего «шума» картинки** (`GRAIN=0` по умолчанию). Минимализм: без нарисованных купюр, засветок и фокус-стрелок,
    если ролик продающий/экспертный — подписи по словам, стекло с карточкой и цифрами, шаги, призыв.

## Режимы ролика и переходы

| Режим | Что на экране | Когда |
|---|---|---|
| **Живой** | резкое видео, подпись-стопка на груди/под подбородком, ходит за головой | обычная речь |
| **Стекло** | фон размыт (σ≈26) и затемнён ~50 %, поверх — карточка с фото, крупное число или название | цены, сравнения, цифры, названия, перечисления |
| **Вспышка** | чистый экран: белый `#fff`, чёрный `#121214`, кремовый `#f2eee7` или пыльно-розовый `#c79ea4` (текст `#5b1d2a`); 2–4 слова или заголовок + список разреженных слов | 2–4 «удара» подряд, смена мысли |
| **Белый Apple-экран** | непрозрачный белый `#fbfbfb`, шрифт SF Pro, оранжевая размытая волна `#f06b4e` снизу/сверху, заголовок с буквами-пружинками, плашки-теги, плитки-виджеты с картинками iOS, выделение текста, список, кнопка-док | объяснение по шагам («Шаг 1/2/3»), обучающие и продающие ролики без человека, интро/финал |
| **Красивые планы** | B-roll (товар, детали) по 0.4–1.2 с под продолжающийся голос | «эмоции», продукт, переход к предложению |

Переходы:
* Живой → Стекло: фокус-рамка на лице + фон уходит в размытие за 0.28 с.
* Стекло → Живой: стеклянное растворение карточки (рябь + расфокус, 0.5 с), снова фокус-рамка.
* Вспышка/Стекло → Живой или → B-roll: световая засветка (оранжево-розовая, 0.45 с) + резкий наезд ×1.08–1.12.
* Кульминация «деньги/выгода»: дождь из купюр, последняя огромная купюра закрывает склейку.
* Заголовок → заголовок: вверх с расфокусом, новый печатается; или перемешивание букв (TAOBAO → POIZON).
* Начало ролика: можно силуэт (человек залит чёрным 0.3–0.4 с) или сразу первая подпись.
* Внутри длинного плана: плавный наезд (`zoom` с `ramp` 0.5) на смене мысли.

## Белый Apple-экран (снято с референса «монтаж Apple за 3 шага»)

* Фон `wb` (белый, непрозрачный — видео под ним не видно); волна `wave` поднимается снизу за 0.8 с, неровный «рваный» край, размытие 26.
* Заголовок `btext` mode `bounce`: буквы по одной (шаг 45–60 мс) выпрыгивают пружиной из scale 0.35 и сначала стоят врозь,
  потом съезжаются; SF Pro Heavy 104–112. Вторая строка — `slide`: слово въезжает слева из размытия, серое → чёрное (SF Regular 62–70).
* Плашка `pill` (оранжевый градиент, белый жирный текст) прилетает снизу-слева с поворотом и встаёт пружиной.
* Плитка `tile` (скругление 64, мягкая тень): эмодзи или картинка из пака `@local/ui/…`, баунс-появление, `swap` — смена картинки
  с прыжком, уход `circle` (сжимается в круг) или `up`.
* Блок переезжает вверх пружиной (`move: [[t, y]]`), освобождая место плитке.
* Стеклянный шар — **как в референсе**: небольшой (r≈150–190), катится, переворачивает буквы внутри, мутнеет и растворяется (`fadeOut`), из него расходится белый `circle`; **не раздувать на весь экран** (пользователь: «как будто лупу приблизили»).
* Переходы: стеклянный шар `ball` проезжает по заголовку (переворачивает и увеличивает текст под собой), мутнеет до лавандового,
  растёт и стирает экран; белый круг `circle` вырастает снизу; волна сверху (`wave from:"top"`) между шагами; уход блоков вверх с размытием.
* iOS-выделение `select` (синяя подсветка растёт с печатью, ручки), список `list` (печать по буквам, серое → чёрное),
  тёмная кнопка-док `dock` с папкой, `swap` → синяя кнопка «забрать всё!». Ник сверху — `handle`.
* Звук: каждая буква заголовка/выделения/списка — щелчок `эпл печатание`; волна/шар/круг — вуш (`вуши для разгона`); слово въезжает —
  `Резкие вуши`; плашка — `ui-pop-up`; плитка/док — `трансформация 1`; смена картинки/кнопка — `App Click 15`; мутнеющий шар — `small_whoosh_chimes`.
* **Плавность (правка пользователя «нет той плавности, дёшево»):**
  - вход — «камерой»: вся композиция в группе (`group`, `"g":"id"`) вылетает из точки (scale 0.1 → 1 за 0.75 с, мягкая пружина);
  - буквы рождаются маленькими (≈22 %) на своём месте у линии шрифта и дорастают — ширина строки не меняется, строка не дёргается;
  - пружины мягкие (перелёт 2–5 %), длительности 0.6–0.8 с; никаких резких рывков;
  - 60 кадров/с и размытие в движении: `"fps":60, "mblur":6, "shutter":0.5` (меньше 5 подкадров — на быстрых сдвигах текст двоится) в cues (рендер дольше в 3 раза);
  - волна мягкая: крупные медленные бугры, размытие 42;
  - **никаких эмодзи** в белом режиме — только картинки и иконки из пака (`@local/ui/icon_*.png`, скриншоты iOS); значок ника — монограмма.
  - смены шагов: плитка сжимается в круг + волна снизу; блок падает (`exit:"drop"`) + волна сверху; новый заголовок входит с наклоном (`enter:"tilt"`).
* **Ролик «под голос» в белом режиме** (пример-генератор `engine/examples/voice_white_gen.py`): каждая фраза — сцена,
  заголовок буквами-пружинками **по словам** (`"words": [["слово", t], …]` — буквы слова начинаются в момент произнесения),
  второстепенные строки — `mode:"word"`; виджеты: `numcard` (цифры печатаются, линия зачёркивает, число сменяется — «5 000 ₽ → 0 ₽»),
  `assemble` (формы слетаются в объект), `eqtile` (эквалайзер и круги по голосу, всплеск на ключевом слове), `vcard` (волна
  строго по голосу, точка записи), `tile` со `swap: [[t, "картинка|46", фон], …]` (смена виджета на ударных слогах),
  `select` с выходом `erase`, `arrow`, `dock2` (подпись кнопки по словам, `swap` → синяя кнопка, `scale`).
  Огибающая голоса (`env`, `envFps`) и длинные паузы (`pauses`) кладутся в cues — в паузах > 0.7 с движение замирает.
  Звуки — только явными `{"type":"sfx"}`: смена сцены — вуш, ключевое слово — щелчок/поп, большие акценты — `tagpop`;
  у остальных элементов `"sfx": false`. Переходы — все из референса: белый круг, сжатие плитки в круг, падение вниз + волна
  сверху, вход с наклоном, стеклянный шар (`fadeOut` — растворяется в белый), уезд влево, стирание выделения.
  Гамма: `"wbColor"` (волна, круги) и `"wbPill": [светлый, тёмный]` (плашки) в cues — бело-синяя: `#3d7ef5`, `["#6aa6ff","#2f6df2"]`.
  Правки пользователя: «листание обычных картинок» не годится — сцена должна показывать смысл фразы (`prompt`: поле ввода,
  текст печатается, «отправить»; чипы-части → галочки; `reels`: превью роликов из уже отрендеренных сцен). На фразу про звук —
  серия быстрых UI-звуков (`fx1..fx11` из пака) с всплесками `eqtile.bursts`, тишины после слов не оставлять.
  Иконка Claude — своя отрисовка «искры» на терракотовом фоне (`tile.html`).
  `follow` — подписка как в референсе: кнопка «Подписаться» в плитке разворачивается в карточку профиля (аватар из фото
  пользователя, ник, подпись) и на ключевом слове нажимается -> «Вы подписаны ✓» (вместо «неудивительной» абстрактной анимации).
  Плашка-иллюстрация появляется ровно в тот момент, к которому относится (звук — в паузе, когда звучат эффекты), а не с начала фразы.
  Пауза в начале записи убирается (резать за ~0.1 с до первого звука). Первый и последний кадр — чистый белый (бесшовный цикл).
* Пример: `engine/examples/white_apple.json` (на пустом белом видео 60 к/с; `GRADE=0`, `LOUDNORM=0`).

Стопка: 2–4 строки, мелкое слово прижато к левому краю ключевого сверху или к правому снизу, строки почти касаются.
Акценты в строке: `"b"` — жирное слово, `"a"` — оранжевое. Подпись под подбородком: `"chin": 1.0` в cues для человека
с бородой (по умолчанию 0.80 — иначе текст налезает на бороду, особенно когда человек наклоняется). Скобки `>слово<`, теги `[ … ]`, курсор печати `слово|`.
Внизу можно держать подпись-водяной знак (`mark`): имя моноширинным + крошечная строка капсом.

## Анимации

* Слово: градиентная шторка слева направо + расфокус 7 → 0 (обычные подписи) **или** «кино»: из крупного расфокуса
  (scale 1.18 → 1, blur 14 → 0, 0.28 с) — `"fx":"cinema"`. Блок уходит расфокусом 0.16–0.22 с или свайпом влево.
* Печать: шаг 40–70 мс, буква из расфокуса, серый → белый; на вспышке разрядка сжимается.
* Карточка с фото: влёт пружиной (3D-поворот), подписи сверху/снизу, цена появляется на слове (`bt`), перелистывание под стеклянной линзой.
* Заголовок на стекле: печать по буквам, взмах вверх (`up`), пояснение ниже.
* Текст **за спиной** человека (`behind:true` + маска `matte.py`): голова перекрывает буквы.
* Караоке-абзац: вся фраза серая, сказанное — белое; выравнивание к человеку.
* Призыв: `caps` + `"+"` + прыгающий шеврон вниз.
* Дополнительно (старый движок `style-lab/reel.py`): цветовая вспышка, глитч-полосы с RGB-сдвигом, постеризация, коллаж из 3 кадров.

## Цвет

* **Стандарт стиля — `GRADE=film FILM=1.3`** (просьба пользователя: «фильтр как в фильмах, приятная картинка, насыщенность без передоза»):
  плёночная S-кривая с мягким плечом в светах, плотный чёрный, тени чуть холоднее / света чуть теплее, вибранс (+≈25 % насыщенности:
  тусклое ярче, кожа почти без изменений), зелень спокойнее и чуть в оливу; **средняя яркость кадра сохраняется** — не светлее оригинала.
  Проверять до/после на 2–4 кадрах: яркость (Y) равна, насыщенность +20…30 %, не больше.
* `GRADE=0` — как снято; `GRADE=1` — старый мягкий вариант.
* Для тёмной, «киношной» картинки — `GRADE=cinema`: плотный контраст, тени в бирюзу, тёплая кожа, приглушённая зелень, матовые чёрные.
* Виньетки нет (правило 4). Зерна нет (правило 13; `GRAIN=0.006` — только по просьбе).

## Звук

Паки пользователя: Botanica v5 и пак «Apple» (звуки + шрифты SF Pro + картинки iOS). Сопоставление спектров со всеми референсами:
в видео 4 и 9 пак «Apple» совпадает сильнее (z 18–42), чем Botanica, — значит там стоял он; роли ниже переведены на него.
Громкость задаётся **относительно голоса** (`compose.py` меряет голос; без голоса — −24 dBFS).

| Событие | Роль | Файл пака | Относительно голоса |
|---|---|---|---|
| новая подпись (блок), абзац, заголовок, призыв | `blockpop` | эпл печатание (кусок с 1.09 с) | +3 дБ |
| добавочная строка в стоящем блоке | `linepop` | эпл печатание (с 2.41 с) | −5 дБ |
| строка, которая печатается | `typeone` | clickbutton (с 32.16 с) | −3 дБ |
| печать по буквам (вспышки, заголовки) | `key1..4` | Type (one) 1–4 | ≈ −6 дБ |
| тег `[ … ]`, финальная цифра | `tagpop` | notification3 | −1 дБ |
| строка вспышки / окно интерфейса | `cardclick` | App Click 15 | −2 дБ |
| влёт карточки / линза | `tink` | Pop, Button, Scale, Transform, Ui_15 | — |
| перелистывание карточки | `click2` | Pop, Button, Scale, Transform, Ui_8 | — |
| дождь из купюр | `cash` | Cash, Coin, Paid | — |
| засветка, растворение, шторка | `riser`, `shimmer`, `swoosh` | синтез (в паке подходящих нет) | тихо |

Файлы пака в git не кладём: таблица роль → файл — `engine/sfx_map.json`; один раз
`python engine/pack_to_sfx.py "/папка/Botanica" "/папка/пака Apple"` → `engine/sfx_local/` (в `.gitignore`;
`start` в таблице — кусок из файла-сборника). Шрифты и картинки iOS: `python engine/pack_assets.py "/папка/пака Apple"` →
`engine/local/` (тоже в `.gitignore`); в cues — `"img":"@local/ui/Battery10.png"`. Без пака: Inter и синтез-звуки. Другой набор — `SFX_MAP=… pack_to_sfx.py`
и `SFX_LOCAL=…` при сборке. Без пака работают синтезированные заменители (`engine/sfx/`, те же роли).
Плотность: ≈ 1 звук на 1.5–4 с; строки, появившиеся вместе, — один звук. Новые звуки от пользователя — сначала найти их
в референсах (сопоставление спектров), потом вписать в эту таблицу.

## Как делать ролик

1. Сказать пользователю, сколько ждать (30 с ролика: разметка ~15 мин, рендер+сборка ~10 мин).
2. Клипы: повернуть/вписать в 1080x1920, 30 к/с (`ffmpeg -vf scale=1080:1920,fps=30`), склеить по сценарию;
   B-roll — под продолжающийся голос (L-склейка).
3. Тайминги слов: `python video-tools/words.py src.mp4 words.json` (GigaAM v2, офлайн). Склейки — `scenedetect`.
4. Лицо: `python engine/anchor.py src.mp4 anchor.json`. Маска (для «за спиной», силуэта, замены фона): `python engine/matte.py src.mp4 matte/`.
5. `cues.json` (ниже; примеры — `engine/examples/`). Фото для карточки — кадр из B-roll.
6. `node engine/render.js cues.json ov/` (≈ 14 кадров/с).
7. `SFX_LOCAL=… [GRADE=cinema] [MATTE=matte] python engine/compose.py src.mp4 ov/ out.mp4` (≈ 2.3 кадра/с, в фоне;
   `FROM/TO` — кусок, `SPEED`, `SFX_GAIN`, `AUDIO_ONLY=1` — только звук, `LOUDNORM=0` — без нормализации).
8. Проверка: лист кадров на ключевых моментах, читаемость, громкость (−14…−16 LUFS, пик ≤ −1 dBFS).
9. Отдать файл в чат; названия/цифры, в которых не уверен (распознавание), — показать пользователю.

 "items":[

     {"size":"l","words":[["мотоцикл",0.79]]}]},                       // "fx":"cinema" — из расфокуса, на груди; "pos":[x,y] — вручную

## Примеры

`engine/examples/ad_moto.json` — реклама мотоцикла (цены Россия/Китай, B-roll, шаги, деньги, призыв);
`glass_demo.json` — все приёмы стекла; `kino_demo.json` — силуэт, текст за спиной, абзац, вспышки, печать.
`no_voice_walk.json` — ролик без речи (прогулка): свой нейтральный текст, абзац-караоке в темпе чтения, вспышки,
«ЛЕС» за спиной проходящего человека, финал с датой из имени файла и тегом. Без голоса: `LOUDNORM=0`, затем `-af aresample=192000,volume=7dB,alimiter=limit=0.6:attack=1:release=50:level=disabled,aresample=48000`
(лимитер с передискретизацией: без него пики выходили за 0 dBFS). Всегда проверять пик (`ebur128=peak=true`) ДО отправки.
Фото и видео к примерам в репозитории нет — подставить свои.

## Нельзя

* Брать звуки/картинки из чужих роликов; коммитить видео пользователя, референсы и файлы купленных паков.
* Музыка без просьбы; виньетка; мультяшность; плашки под субтитрами.
* Перекраивать ролик целиком при просьбе о маленькой правке.
