# Стиль «apple-reels»: разбор 4 референсов

Источник: 4 вертикальных ролика (9:16), 15–37 с: автодетейлинг, обзор «G-class», недвижимость, автосалон.
Цифры посчитаны скриптом `analyze.py`, оформление текста и переходов описано по кадрам (я вижу кадры, а не движение).

## Общая формула

Говорящий человек в кадре + короткие фразы-титры по 2–4 слова, которые «проявляются» в такт речи,
спокойный кинематографичный цвет и редкие акценты: наезд, вспышка, глитч, UI-плашка.
Много воздуха, мало цветов, ничего мультяшного.

## Монтаж

| Ролик | Длина | Склеек | Средний план | Склеек / 10 с |
|---|---|---|---|---|
| Автодетейлинг | 19 с | 5 | 3,8 с | 2,1 |
| G-class (факты) | 14,9 с | 13 | 1,1 с (медиана 0,4) | 8,1 |
| Недвижимость | 29,5 с | 6 | 4,9 с | 1,7 |
| Автосалон | 36,8 с | 13 | 2,8 с | 3,3 |

- Говорящая голова держится 3–15 секунд **без склеек**: оживляют цифровым наездом (масштаб 1,08–1,15 на акценте, плавный возврат).
- Быстрый монтаж (G-class) — вставки по 0,15–0,6 с: детали машины, размытие в движении, коллаж из 3 кадров друг над другом.
- Склейки жёсткие, по речи. Переходы-акценты: **цветовая вспышка** (оранжевая/красная на 0,25 с), **горизонтальные полосы-глитч с RGB-сдвигом**, **постеризация** (чёрно-белый «плакатный» кадр, красная заливка).

## Цвет

- Приглушённый, кинематографичный: средняя яркость 0,23–0,41, насыщенность 0,22–0,34.
- Тёмные тона холодные (сине-зелёные), света чуть тёплые; приподнятые чёрные (матовая картинка), мягкое свечение светов, виньетка.
- Палитра автодетейлинга: `#0b0b0e` `#232629` `#414846` `#64706a` `#91a798`. Недвижимость: `#2c2a35` `#d8dee3` `#5a4e47`.
- Акцентные цвета только в эффектах: оранжевый `#ff6e14`, красный, синий UI `#3b3df4`.

## Текст

- Шрифт: гротеск (по виду Inter / Neue Haas), точное название по кадрам определить нельзя.
- Заголовок: **строчные буквы, жирный (700), очень плотный трекинг (−4,5 %)**, белый, 1–2 строки по центру.
- Подзаголовок: тонкий (300), мелкий, **широкий трекинг (+18 %)**, полупрозрачный.
- Тег в скобках `[ подпишись ]`, `[ через неделю ]`: мелкий, скобки разнесены по краям.
- Положение: центр, на уровне груди говорящего (55–68 % высоты). Иногда выравнивание влево.
- Анимация: **слово за словом проявляется из размытия** (размытие 16 px → 0, подъём 26 px, задержка 0,08 с между словами, 0,55 с на слово), уходит обратно в размытие за 0,3 с. Фразы живут 0,5–1,4 с.
- Акценты: курсивный «слэнтованный» заголовок; смесь шрифтов (латиница курсивом: `history`); тонкие высокие цифры (`2025 / 1998 / 1978`) с бледным «призраком» предыдущей.
- Интерлюдия: на 1–3 с полноэкранная **тёмно-синяя карточка**, по одному приглушённому серому слову (`прописан`… `не`… `живете`), как караоке.
- UI-вставки: синяя «пилюля»-кнопка с белым текстом, круглая аватарка с градиентным кольцом, конфетти с эмодзи на ключевом слове.
- Водяной знак: ник внизу по центру, мелко, 35–55 % прозрачности (рукописный или тонкий).

## Звук

- Громкость высокая: −11…−16 LUFS. В двух роликах пики выше 0 dBFS, то есть звук «перегружен». В шаблоне берём −14 LUFS без клиппинга.
- Речь доминирует. Всплески (≈ 36–40 штук на ролик) — это эффекты на склейках и акцентах: свист, удар, мелкий щелчок на появление текста.
- Определить, есть ли в роликах музыка, автоматически не удалось. Тест на ритм дал разные значения (96–161 bpm), им нельзя верить.

## Как использовать как шаблон

Файлы в `style-lab/`:

- `style.json` — все параметры (текст, цвет, наезды, вспышка, глитч, звук).
- `overlay.html`, `render_overlay.js` — рендер текстов, карточек, цифр и плашек.
- `reel.py` — сборка ролика: вписывание в 9:16, наезд, грейд, вспышки, глитч, текст, зерно, звуки.
- `analyze.py` — разбор нового референса в такие же цифры.
- `demo_cues.json` — пример разметки (реплики и эффекты по времени).

```bash
python style-lab/reel.py исходник.mp4 cues.json готово.mp4 --fit blur   # --fit cover: на весь кадр
```

Для нового ролика достаточно написать `cues.json`: что и когда показать. Тайминги берём из речи (когда дойдёт до расшифровки,
она даст их автоматически).

## Что в шаблоне пока упрощено

- Нет конфетти, аватарки с кольцом, коллажа из 3 кадров, постеризации, ускорений/замедлений (speed ramp) и «слэнтованного» шрифта.
- Склейки не ставятся автоматически: расставляются вручную в `cues.json` (наезды, вспышки, глитчи).
- Шрифт — Inter, он близок, но не идентичен референсам.
